# MEye-Pro frontend

Run `npm ci` and then `npm run dev` from this folder. Open http://localhost:3000.

The demo accepts any nonempty password. Use demo@student.edu, demo@teacher.edu, demo@admin.edu or demo@director.edu to open the corresponding workflow. Screens use the Figma prototype's example data.

Next.js entry pages are in `src/app`. The original screen components, role logic and shared UI are in `src/monitor`. Desktop layouts use a sidebar from 860 px upward. Narrower screens use the original bottom navigation.

Run `npm run build` for a production build.
